# GEVP to Lanczos

Numerical implementations and validation tools for the Generalized Eigenvalue Problem (GEVP) and block-Lanczos spectral reconstruction in lattice field theory.

## Repository Structure

- `GEVP/` - GEVP analysis code and related materials.
- `Lanczos/` - Block-Lanczos implementation, numerical diagnostics, and validation notebooks.

## Current Contents

- `Lanczos/Noiseless_mock_data_Oblique_block_lanczos.ipynb` - Notebook for noiseless mock-data analysis using oblique block-Lanczos methods, including numerical diagnostics and an investigation of the printed Eq. 24 identity.

## Requirements

Python and scientific-computing dependencies will be documented after checking the notebook imports.

## Status

Research code under active development. Numerical comparisons support validation and investigation; discrepancies should be assessed alongside the derivation and assumptions of the underlying method.
